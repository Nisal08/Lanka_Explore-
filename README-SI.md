# Lanka Explorer — සිංහලෙන් ඉක්මන් උපදෙස්

මෙය GitHub Pages මත publish කළ හැකි static website එකක්. `index.html`, `css/`, `js/`, `data/` සහ `images/` මේ project folder එකේ root එකේම තියෙනවා.

## VS Code වලින් run කරන්න

1. VS Code වල `lanka-explorer` folder එක open කරන්න.
2. **Live Server** extension එක install කරන්න.
3. `index.html` මත right-click කර **Open with Live Server** තෝරන්න.
4. `file://` මඟින් direct open කරන්න එපා — JSON fetch සහ APIs ක්‍රියා නොකරන්න පුළුවන්.

## GitHub Pages publish කරන විදිහ

1. GitHub එකේ **public repository** එකක් හදන්න; උදාහරණයට `lanka-explorer`.
2. මේ folder එකේ **ඇතුළත files** සියල්ල repo root එකට upload කරන්න. Repo එකේ root එකේම `index.html` පෙනෙන්න ඕන.
3. GitHub repo → **Settings → Pages** යන්න.
4. **Build and deployment → Source → GitHub Actions** තෝරන්න.
5. `main` branch එකට upload/push කළාම project එකේ `.github/workflows/pages.yml` deploy workflow එක run වෙනවා. **Actions** tab එකෙන් success වෙනකම් බලන්න.
6. GitHub පෙන්වන link එක `Hosted Link.txt` සහ `README.md` තුළ දාන්න.

සාමාන්‍ය URL එක: `https://ඔබගේ-username.github.io/lanka-explorer/`
