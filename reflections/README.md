# Individual reflections — complete one per group member

The assessment requires a short personal reflection (about 150 words) from each member. These are deliberately left as honest prompts rather than invented first-person claims. Duplicate the template below for each real member, write about what that person actually contributed, and use the member's own words.

## Template (about 150 words)

**Name:** [member's real name]  
**Role:** [role actually performed]

**Reflection:**

During this mini project, I worked on [specific pages / feature / code]. My main contribution was [what you personally built or researched]. I learned [one or two ideas, such as semantic HTML, responsive CSS, `fetch` and JSON, array filtering, APIs, `localStorage`, or GitHub Pages], and I can explain how [specific piece] works. The most challenging problem for me was [real problem]. I approached it by [what you tried], and I solved it by [the fix / what you learned]. I tested my work by [real test, screen width, API failure or validation]. If I had more time, I would improve [specific next step]. This project helped me understand [personal takeaway about teamwork / web development].

> Replace every bracket with real details and revise the wording so each reflection is genuinely individual. Do not submit the template unchanged.
