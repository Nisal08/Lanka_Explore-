Our little idea

A pocket-sized guide to a big-hearted island.

We built Lanka Explorer as a practical starting point for discovering the Pearl of the Indian Ocean. Search the destinations, learn a little about each place, check the weather and make a simple route of your own.

This mini project brings together semantic HTML, responsive CSS, JavaScript, JSON data, browser storage and a few public APIs. It is a learning project, so always verify travel details with official sources before a real visit.
