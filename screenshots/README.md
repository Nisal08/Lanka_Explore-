# Responsive screenshots

This folder contains the requested 20 full-page screenshots: all five pages at 375px and 1280px, in light and dark mode. They were captured from the local HTTP preview with Chromium on 2 November 2026. The Trip screenshots show three sample saved destinations and two travellers; other pages show the normal demo state.

Files are named `{page}-{width}-{theme}.png`, for example `home-375-light.png` and `details-1280-dark.png`.
